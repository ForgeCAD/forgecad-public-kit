# ForgeCAD

Agentic CAD for the physical world.
ForgeCAD agents build simulation-ready 3D assets for physical AI and export them to OpenUSD, MJCF, URDF, and STEP.

- Open ForgeCAD: [forgecad.io](https://forgecad.io)
- Read the docs: [forgecad.io/docs](https://forgecad.io/docs)
- Connect your own agent through MCP: [guide](https://forgecad.io/docs/ai-agents)

```bash
claude mcp add --transport http forgecad https://forgecad.io/mcp
```
